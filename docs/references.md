# Références

- [Spécification MCP](https://modelcontextprotocol.io/specification/latest) : transport, outils et sécurité.
- [Configuration MCP officielle de Codex](https://developers.openai.com/codex/mcp/) : connexion Streamable HTTP et jeton Bearer.
- [API officielle Foundry VTT](https://foundryvtt.com/api/) : contrat normatif des API publiques.
- [Système D&D5e](https://github.com/foundryvtt/dnd5e) : modèles et comportements D&D5e.
- [Foundry VTT Community Wiki](https://foundryvtt.wiki/en/home) : guides pratiques et exemples.
- [Plutonium Next](https://github.com/TheGiddyLimit/plutonium-next) : distribution du module dont les données locales peuvent être indexées.
- [5etools](https://5e.tools/) : format et catalogue de contenu D&D5e. Le projet lit les copies JSON locales sans scraper le site ni exécuter le code du module.

L’API officielle Foundry prévaut sur le wiki communautaire. Le protocole Socket.IO utilisé par le backend direct doit être revérifié à chaque upgrade majeur de Foundry.
