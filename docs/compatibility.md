# Compatibilité

| Composant | Version certifiée |
|---|---|
| Node.js | 22.x |
| Foundry VTT | 14.367 |
| D&D5e | 5.3.3 |
| Plutonium | 2.18.1.v14 et 2.18.3.v14 |
| Navigateur | Chromium récent |

Un navigateur GM actif et connecté est une précondition de fonctionnement. Plutonium est optionnel ; ses versions `2.18.1.v14` et `2.18.3.v14` sont certifiées. Les versions non testées échouent fermement pour les imports Plutonium.
